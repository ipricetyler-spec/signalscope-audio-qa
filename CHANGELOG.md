# Changelog

All notable changes are documented here. The project follows semantic versioning.

## [1.0.0] - 2026-08-18

### Added

- Local browser decoding for user-selected audio files.
- Peak, RMS, crest-factor, DC-offset, channel-balance, and stereo-correlation metrics.
- Timestamped clipping and extended-silence findings.
- Deterministic signal-health scoring with documented thresholds.
- Canvas waveform visualization and issue markers.
- Engineered demonstration signal containing known defects.
- JSON and CSV report export.
- Responsive, keyboard-conscious interface and privacy documentation.
- Bun tests, strict TypeScript checks, CI, and GitHub Pages deployment workflow.
