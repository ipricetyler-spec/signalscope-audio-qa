# Upwork portfolio entry

## Title

SignalScope — Privacy-First Browser Audio QA Workbench

## Role

TypeScript application developer and audio-analysis engineer

## Description

Built a browser-based audio quality workbench that detects clipping, extended silence, stereo imbalance, and possible DC offset without uploading client recordings. SignalScope decodes audio locally with the Web Audio API, visualizes the waveform and timestamped findings, calculates documented signal metrics, and exports structured JSON or CSV reports.

The analysis engine is separated from the interface and covered by boundary-focused automated tests. The project includes responsive and keyboard-conscious UI behavior, explicit privacy constraints, reproducible synthetic demonstration data, CI verification, and documented technical limitations rather than unsupported accuracy claims.
