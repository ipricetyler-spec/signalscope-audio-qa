# Security policy

## Supported versions

Security fixes are applied to the latest `1.x` release and the default branch.

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Use the repository's **Security → Report a vulnerability** private-advisory flow and include:

- affected version or commit;
- realistic impact and preconditions;
- reproduction steps or a minimal proof of concept;
- suggested mitigation, if known.

Expect an initial acknowledgement within seven days. Timelines for validation and remediation depend on severity and reproducibility. Please allow a reasonable remediation window before public disclosure.

SignalScope has no backend, account system, or intended network transmission. Reports involving unexpected data transfer, unsafe browser parsing, dependency compromise, or export injection are especially relevant.
